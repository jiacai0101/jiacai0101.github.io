A freely accessible deep-learning web server for end-to-end CYP450 metabolic profiling.

## Highlights

- Covers nine major CYP isoforms in a unified pathway–site–product pipeline.
- Multi-task graph neural network with multi-scale descriptors, operating directly on 2D molecular graphs.
- Supports high-throughput batch processing for early metabolic-liability assessment.
