ADMETlab 3.0 is the second updated version of the web server that provides a comprehensive and efficient platform for evaluating ADMET-related parameters as well as physicochemical properties and medicinal chemistry characteristics involved in the drug discovery process. This release includes 119 features (an increase of 31 over the previous version) and over 400,000 data entries. ADMETlab 3.0 incorporates a multi-task DMPNN architecture coupled with molecular descriptors, achieving superior accuracy and robustness. An API has been introduced for programmatic access, and uncertainty estimates are provided to aid confident compound selection.
